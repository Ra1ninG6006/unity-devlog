## 代码与学习要点

- `WeaponData` 保存单件装备的数据；`WeaponLibrary` 用 `ScriptableObject` 保存基础配置；`PlayerEquipment` 保存本局实例。
- `List<WeaponData>` 是装备列表，索引从 `0` 开始；按键 `1/2/3` 对应位置 `0/1/2`。
- `Clone()` 复制模板，避免本局锻造改掉所有后续装备的基础数值。
- `RangedWeaponAttack` 判断输入、冷却与方向，负责生成投射物；`WeaponProjectile` 负责飞行、碰撞和扣血。
- 每枚投射物发射时保存伤害，之后换武器或锻造不会改变已经飞出的那一枚。
- 每枚投射物用自己的 `HashSet<EnemyHealth>` 记录已命中的敌人，避免同一枚重复扣血；三枚仍可分别命中同一敌人。
- `Physics2D.CircleCastAll()` 检查本次移动路径，按距离处理命中，墙体可以拦截投射物。

```csharp
for (int i = 0; i < count; i++)
{
    // 每轮计算方向并生成一枚投射物。
}
```

- `count = 3` 时，`i` 依次为 `0、1、2`，循环体执行三次，因此生成三枚。
- 直接写三份生成代码也能实现；循环复用相同操作，还能根据 `i` 计算不同角度。以后改变数量时修改配置即可。
- `float` 支持 `0.5` 伤害；`ToString("0.##")` 让血量数字显示为 `3` 或 `2.5`，不强制补小数零。
